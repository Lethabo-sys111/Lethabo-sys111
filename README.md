## 📌 Featured Projects

### 🚁 [LethaboDrone](https://github.com/Lethabo-sys111/LethaboDrone)
A drone that teaches itself to navigate randomly generated hilly terrain and avoid obstacles, trained with **reinforcement learning (PPO)** in Unity ML-Agents. I ran a sensor ablation experiment: ground sensors raised the success rate from **51% to 69.5%**.
`Unity` `C#` `ML-Agents` `Python`

### 📷 [Smart Camera Surveillance (Sentinel)](https://github.com/Lethabo-sys111/smart-camera-surveillance)
A Raspberry Pi home security system. When armed, it detects motion, photographs the intruder, sounds a siren and sends a Telegram alert with a call. It is disarmed by NFC card or from a React + Laravel web dashboard with a live feed.
`Raspberry Pi` `Python` `Laravel` `React` `NFC` `IoT`
